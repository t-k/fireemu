# Firestore Standard / Native gRPC data surfaces: local inventory

This artifact decomposes the four `FS-DATA` gRPC surfaces into finite local obligations. It records local execution only; it does not establish production, official emulator, REST, or SDK parity.

| Surface | Atomic local obligation | Existing local evidence |
| --- | --- | --- |
| `FS-COMMIT` | A unary Commit accepts ordered writes, returns one ordered `WriteResult` per write, and publishes one commit time. | `crates/fireemu-adapter-grpc/tests/local.rs`: `commit_get_query_and_delete_round_trip`, `create_update_with_mask_transforms_and_preconditions` |
| `FS-COMMIT` | Commit validation and precondition failure are atomic: no earlier write, field, timestamp, or database version is published when a later item fails. | `crates/fireemu-adapter-grpc/tests/local.rs`: `malformed_wire_shapes_are_rejected_before_any_mutation`, `transaction_commit_late_precondition_failure_preserves_documents_and_versions`, `verify_writes_check_preconditions_without_changing_anything` |
| `FS-BATCHWRITE` | A BatchWrite response preserves one status slot and one `WriteResult` slot for every input position, including failed items. | `crates/fireemu-adapter-grpc/tests/local.rs`: `batch_write_continues_after_decode_and_execution_failures` |
| `FS-BATCHWRITE` | BatchWrite failures are per item: later items continue, successful post-state is visible, and a contended item remains unchanged. | `crates/fireemu-adapter-grpc/tests/local.rs`: `batch_write_reports_lock_contention_per_item_and_preserves_suffix` |
| `FS-BATCHWRITE` | REST rejects a present non-array `writes` field before dispatch, preserving state for malformed scalar and null payloads. | `crates/fireemu-adapter-grpc/tests/rest.rs`: `batch_write_rest_rejects_non_array_writes_without_mutation` |
| `FS-WRITE` | The bidirectional stream performs a database handshake, preserves request and acknowledgement order, returns fresh stream/commit metadata, and applies writes. | `crates/fireemu-adapter-grpc/tests/streams.rs`: `write_stream_handshake_then_sequential_commits`, `write_stream_accepts_pipelined_acknowledgements_and_once_targets_are_removed`, `write_stream_preserves_order_preconditions_transforms_and_post_state` |
| `FS-WRITE` | Half-close and malformed or ownership-invalid stream requests do not publish mutations; active transaction contention is refused without mutation. | `crates/fireemu-adapter-grpc/tests/streams.rs`: `write_stream_graceful_half_close_has_no_side_effect`, `write_stream_enforces_handshake_and_database_ownership`, `write_stream_refuses_active_transaction_contention_without_mutation` |
| `FS-FILTER-ENUM` | All ten non-`UNSPECIFIED` `FieldFilter.Operator` values decode and execute through local gRPC query handling; an unknown numeric value is refused as `INVALID_ARGUMENT`. | `crates/fireemu-adapter-grpc/tests/local.rs`: `grpc_field_filter_enum_values_are_executable_and_unknown_values_refused`; `crates/fireemu-adapter-grpc/tests/gateway.rs`: `malformed_parent_and_unknown_operator_are_invalid_argument` |

The finite matrix covers the local Standard/Native gRPC boundary represented by the current handlers. It does not enumerate every protobuf field, oneof, value boundary, query combination, or method in the Firestore API. Production observations and separate REST and SDK executions remain required before parity claims can be made.
