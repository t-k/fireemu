# Offline observation A preparation

Run `node conformance/src/pubsub-observation/compare.mjs --input input.json --input-sha256 INDEX_SHA256 --out new-report.json`. The output is exclusive. This command reads explicit local files only; it performs no network requests, recorder admission, daemon launch or credential loading.

The input index has a required `source` and an optional `local`. Each bundle has `schema: 1`, `evidenceKind` (`production`, `local` or `fixture`), and five pins: `packet`, `descriptor`, `capture`, `issued` and `summary`. Every pin has `path` and `sha256`. Production bundles also require a pinned `coordinatorManifest` covering the capture, issued journal and summary. Keep the input index, all run artifacts and output private. A local bundle describes a replay of the same source run ID, frozen packet and descriptor, rather than a different production recording. Synthetic bundles must be labelled `fixture`.

With source only, the tool inventories all 32baseline cells, records the five unused reservations as non-witnesses and retains request bodies independently from REST `routeName`. Explicit dispatch timestamps are used; fractional monotonic durations are preserved. Requests with omitted large strings require exact reconstruction proof before replay. The summary must bind its capture/issued digests and match the captured cell results. Raw native blobs are checked for relative filenames, bounds, SHA256 and decoded-body agreement using the pinned SDK. Missing or inconsistent frames remain evidence debt.

With a supplied local journal, unary rows use the existing STREAM-DLQ `judgeRow` and causal publication bindings. Reports retain source dispatch/response sequences, local sequences, known gaps and incomplete observations. Wire layout uses recorded `bodyBytes`, never compact stored JSON. A MATCH means the existing recorded semantic shape and, for REST, physical length criterion matched; it is not byte-exact JSON or a closure verdict. Unknown responses, missing requests, ambiguous identities and unresolved ACK selectors remain NOT_COMPARABLE. Known DIVERGES takes precedence while other debts stay visible.

Native StreamingPull has independent temporal and causal contracts. G4's REST transport denotes setup only; its frames are native gRPC. This preparation does not infer stream semantics from equal frame bodies or promote a 90-second recording into the accepted 30-second invalid-ACK-only witness. Those cells remain NOT_COMPARABLE until a dedicated replay witness is connected. The accepted unknown-to-MATCH restriction and IAM structural needs-review rules are unchanged.

The CLI prepares and compares supplied journals. Local replay generation, strict runtime/build/configuration verification, two final-artifact complete-case replays, actual new production recordings and closure review remain outstanding. Reports explicitly retain `replayExecuted: false`, `localRuntimeVerified: false` for comparisons and `parentClosureReady: false`. The canonical closure and frozen recorder are unchanged.
