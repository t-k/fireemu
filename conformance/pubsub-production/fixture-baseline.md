# Read-only fixture baseline collector

`fixture-baseline.mjs` captures exactly three resource calls: project identity GET, the read-only Cloud Resource Manager v1 `getIamPolicy` POST with `requestedPolicyVersion:3`, and IAM v1 GET of the explicitly derived Pub/Sub service account. It never generates a service identity, changes IAM, enables an API or deploys a fixture. The collector itself performs no credential discovery. `baseline-capture.mjs` supplies durable private receipts and an in-process live guard; `baseline_execute.py` supplies a separate coordinator-only entry point with the fixed read-only authority profile. A production invocation requires independently reviewed, signed sources and a separately frozen packet with exact current authority.

The caller supplies credentials, a live admission guard and a durable receipt sink. Both callbacks receive `{signal}` and must honor cancellation. A reservation consumes its slot before awaiting persistence because a lost acknowledgement may conceal a durable write. Headers are persisted before bounded raw body bytes. Recorded HTTP failures are capture evidence; a captured result does not establish baseline usability or compatibility.

`baseline-authority.mjs` is a separate fixed read-only authority checker. Its exact subject/envelope, three-call scope, credential/time bounds, closed version pins and unique E/V/grant parsing cannot admit an owned-resource writing envelope. It reuses the revocation scanner, whose universal global stops are independent of old-version references or delegation wording. The executor must bind its actual fixed request plan and current private ledger to these predicates before credentials and every send.

The collector checks elapsed time after asynchronous work and before declaring capture, bounds all callback, transport and body waits by its overall ten-minute abort, bounds each resource transport by at most thirty seconds, and aborts the owned request on exit. An unlocked response body is cancelled with a one-second cleanup cap. An interrupted operation that has not demonstrably settled sets `terminationRequired:true` and stops the collector. The runner must treat this flag as a required process-termination condition, never as cleanup success. It must prohibit resume, retry and additional sends, terminate and reap the collector process and its relevant descendants, and verify they have exited before releasing the run's lock. Admission, persistence, transport and response operations must execute in that owned process; callbacks delegated to a surviving parent do not meet this contract. The runner must enforce a hard overall process deadline independently, including during a blocked event loop, and preserve uncertain reservations and receipts on failure.

`baseline_process.py` reserves shutdown time inside each parent deadline, tracks the owned child in a separate session, and checks process birth identity, command and arguments before PID-specific signals. The collector has no process-spawn calls. Session census is supplementary detection, not arbitrary descendant containment; session escape and the portable metadata-to-signal race remain explicit limits. Any unexpected descendant invalidates admission even after verified cleanup; the executor retains the lock. Unverifiable metadata or exit must also retain the lock. A persistent observation ledger also requires confirmed absence for every observed PID, including any that leaves the owned session. Every census applies the sticky descendant rule. Cancellation retries preserve the original deadline; main-thread signal handlers defer asynchronous operator signals through shutdown and are restored before the final cancellation check. Positive kernel absence is never inferred from signal delivery or an empty current session alone. These are local source guarantees under the stated no-spawn contract, not production compatibility evidence or send authority.

Source-only tests use injected responses and callbacks without a server or credentials:

```sh
node --test conformance/src/pubsub-fixture-baseline.test.mjs conformance/src/pubsub-baseline-capture.test.mjs conformance/src/pubsub-baseline-authority.test.mjs
python3 -B -m unittest discover -s conformance/pubsub-production -p 'test_baseline_*.py'
```
