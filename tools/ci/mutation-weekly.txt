# The crates the weekly mutation run takes in turn, one line per run (see docs/mutation-testing.md).
#
# Line: `<package> [<file> ...] [!<file> ...]  # <mutant count when written>`. A file is a path from the
# repository root (a cargo-mutants --file glob); `!<file>` excludes it (--exclude). A line with no file
# mutates the whole package. The run of ISO week W takes line (W mod number of lines) of this file, so
# the rotation is fixed by the file. The weekly run has 16 shards of at most 360 minutes: a package too
# large for that is split here by file, and the last line of a split package excludes the files of
# its other lines, so a new file of the package is still mutated by that last line.
# The runners are Linux: a file compiled for macOS only (cfg(target_os = "macos")) cannot be killed there, so it
# is excluded, and a package that is macOS only (fireemu-fd-acl) is not listed.
# Regenerate the counts with `cargo mutants --list -p <package> --file <glob>`.
